# Product Funnel Analysis and Financial Analysis for an E-Commerce 

## Executive Summary:

Using SQL and Power Bi, I pulled a Marketing & E-Commerce Analytical data set to analyze trends and to track orders through the funnel. I tracked the seasonality trends and funnel through a dashboard for clear visualization and understanding. After identifying the seasonality and campaign trends with the addition of how the funnel affects revenue, I recommend simple changes for a higher revenue turnout and conversion:

1. Utilize specific campaigns through certain channels
2. Push advertisement during Holiday season



### Business Problems:
Since our e-commerce dataset heavily relies on customer trends and engagement while using effective marketing campaigns to generate revenue. Stockholders want to understand how well the company is doing based on a funnel analysis and customer behaviors. How can we determine the performance of the company and use campaigns for revenue turnover?


### Methodology:
1. Use SQL queries to clean and transform the dataset for an exploratory data analysis
2. Utilize SQL for an exploratory data analysis looking at revenue on a monthly basis
3. Use a funnel analysis to see performance within the company and use campaign results to optimize performance
4. Create a dashboard on Power Bi to visualize results
